L’equilibre de Hardy-Weinberg : un modele de reference en genetique des populations

Des frequences alleliques aux frequences genotypiques, et le test de conformite

Date de publication

3 août 2026

NoteObjectif du chapitre

L’equilibre de Hardy-Weinberg decrit ce que deviennent, de generation en generation, les proportions des genotypes dans une population ideale. Il fournit un point de reference : quand les proportions observees s’en ecartent, c’est le signe qu’une force evolutive est a l’oeuvre. Nous etablirons le principe, nous verrons pourquoi l’equilibre s’installe en une seule generation, puis nous construirons le test statistique qui permet de confronter des donnees reelles a ce modele.

AstuceVocabulaire de depart
  • Locus : un emplacement precis sur un chromosome, correspondant a un gene. On etudie ici un seul locus.
  • Allele : une variante possible du gene a ce locus. On considere deux alleles, notes A et a.
  • Genotype : la paire d’alleles qu’un individu porte a ce locus. Avec deux alleles, trois genotypes sont possibles : AA, Aa et aa.
  • Homozygote : individu portant deux alleles identiques (AA ou aa). Heterozygote : individu portant deux alleles differents (Aa).
  • Frequence allelique : proportion d’un allele parmi tous les alleles presents dans la population. On note \(p\) la frequence de A et \(q\) celle de a, avec \(p + q = 1\).
  • Frequence genotypique : proportion de chaque genotype parmi les individus.
  • Panmixie : accouplement au hasard, sans preference liee au genotype.

1 Le principe de Hardy-Weinberg

Dans une population ideale, deux affirmations tiennent d’une generation a la suivante.

D’abord, les frequences alleliques restent constantes : la proportion \(p\) de l’allele A ne change pas au fil des generations. Ensuite, les frequences genotypiques se deduisent des frequences alleliques par des formules simples :

\[ f(\text{AA}) = p^2, \qquad f(\text{Aa}) = 2pq, \qquad f(\text{aa}) = q^2 . \]

Ces trois proportions forment bien un tout, car leur somme vaut 1 :

\[ p^2 + 2pq + q^2 = (p + q)^2 = 1 . \]

L’etat decrit par ces formules s’appelle l’equilibre de Hardy-Weinberg. C’est un modele theorique, valable sous des hypotheses precises que nous detaillerons a la section 5.

2 D’ou viennent \(p^2\), \(2pq\) et \(q^2\)

La justification tient au mecanisme de la reproduction. Chaque individu transmet a sa descendance un seul de ses deux alleles, choisi au hasard : ce sont les gametes (cellules reproductrices). Sous accouplement au hasard, un descendant se forme en reunissant deux gametes tires independamment dans la population. La frequence de l’allele A parmi les gametes est justement \(p\).

Un descendant recoit donc l’allele A de son premier gamete avec probabilite \(p\), et de son second avec probabilite \(p\) egalement. La probabilite d’obtenir le genotype AA, c’est-a-dire A des deux cotes, est donc \(p \times p = p^2\). De meme, aa correspond a \(q \times q = q^2\). Le genotype Aa peut se former de deux facons, A puis a ou a puis A, chacune de probabilite \(pq\), d’ou un total de \(2pq\). Le facteur 2 vient de ces deux ordres possibles.

Verifions par simulation. On forme une grande population en tirant, pour chaque individu, deux alleles au hasard avec la frequence \(p\).

Code
p <- 0.6            # frequence de l'allele A
q <- 1 - p          # frequence de l'allele a
N <- 100000         # nombre d'individus

# nombre d'alleles A recus par individu : 0 (aa), 1 (Aa) ou 2 (AA)
nA  <- rbinom(N, size = 2, prob = p)
obs <- prop.table(table(factor(nA, levels = 2:0, labels = c("AA", "Aa", "aa"))))
att <- c(AA = p^2, Aa = 2 * p * q, aa = q^2)

rbind(observe = round(as.numeric(obs), 3),
      attendu = round(att, 3)) |> `colnames<-`(c("AA", "Aa", "aa"))
           AA    Aa    aa
observe 0.359 0.478 0.163
attendu 0.360 0.480 0.160

3 Un resultat frappant : l’equilibre s’installe en une generation

Le point le plus surprenant du principe est sa rapidite. Quelles que soient les frequences genotypiques de depart, une seule generation d’accouplement au hasard suffit pour atteindre les proportions \(p^2\), \(2pq\), \(q^2\), et la population y reste ensuite.

Illustrons-le a partir d’une population volontairement tres eloignee de l’equilibre : 60 pour cent de AA, 40 pour cent de aa, et aucun heterozygote.

Code
N <- 100000
geno0 <- sample(c("AA", "aa"), N, replace = TRUE, prob = c(0.60, 0.40))

# frequence allelique de A au depart : chaque AA porte deux A, chaque aa aucun
p0 <- (2 * sum(geno0 == "AA")) / (2 * N)

freq0 <- prop.table(table(factor(geno0, levels = c("AA", "Aa", "aa"))))

# une generation de panmixie : union au hasard de gametes de frequence p0
nA1   <- rbinom(N, size = 2, prob = p0)
freq1 <- prop.table(table(factor(nA1, levels = 2:0, labels = c("AA", "Aa", "aa"))))
p1    <- (2 * sum(nA1 == 2) + sum(nA1 == 1)) / (2 * N)

c(`freq. A avant` = round(p0, 3), `freq. A apres` = round(p1, 3))
freq. A avant freq. A apres 
        0.599         0.600
Code
tibble(genotype = factor(c("AA", "Aa", "aa"), levels = c("AA", "Aa", "aa")),
       `generation 0` = as.numeric(freq0),
       `generation 1` = as.numeric(freq1)) |>
  pivot_longer(-genotype, names_to = "generation", values_to = "frequence") |>
  ggplot(aes(genotype, frequence, fill = generation)) +
  geom_col(position = "dodge") +
  scale_fill_manual(values = c("generation 0" = "#b0b0b0", "generation 1" = "#4682b4"),
                    name = NULL) +
  labs(x = "genotype", y = "frequence")

La population passe de zero a environ 48 pour cent d’heterozygotes en une generation, tandis que la frequence de l’allele A reste a 0,6. C’est la difference essentielle entre frequence allelique et frequence genotypique : l’accouplement au hasard reorganise les alleles en genotypes selon \(p^2\), \(2pq\), \(q^2\), sans modifier la proportion des alleles eux-memes.

4 Les hypotheses du modele ideal

L’equilibre de Hardy-Weinberg ne decrit pas une population reelle quelconque, mais une population ideale qui satisfait plusieurs conditions simultanement :

  • accouplement au hasard, sans preference liee au genotype ;
  • absence de selection, tous les genotypes ayant la meme survie et la meme fecondite ;
  • absence de mutation qui transformerait un allele en un autre ;
  • absence de migration entre populations ;
  • taille de population tres grande, ce qui rend negligeable le hasard des tirages d’une generation a l’autre (la derive genetique).

Ces conditions jouent ici le meme role que le cas ideal dans le chapitre sur la capture-recapture : elles definissent une reference. Quand les proportions observees s’accordent avec Hardy-Weinberg, aucune de ces forces ne se manifeste de facon detectable. Quand elles s’en ecartent, l’ecart oriente vers la cause. Le modele est donc moins une description qu’un instrument de diagnostic.

5 Estimer la frequence allelique a partir des donnees

En pratique, on ne connait pas \(p\) : on l’estime a partir des genotypes observes. Il suffit de compter les alleles. Un individu AA porte deux alleles A, un individu Aa en porte un, un individu aa aucun. Sur un echantillon de \(N\) individus, la frequence estimee de A est donc

\[ \hat p = \frac{2 \, n_{\text{AA}} + n_{\text{Aa}}}{2N}, \]

ou \(n_{\text{AA}}\) et \(n_{\text{Aa}}\) sont les effectifs observes des genotypes correspondants, et \(2N\) le nombre total d’alleles dans l’echantillon. Ce point est a retenir pour la suite : la frequence allelique est estimee sur les donnees elles-memes, et cela aura une consequence directe sur le test.

6 Tester l’equilibre : le khi-deux et ses degres de liberte

Pour decider si une population reelle s’accorde avec Hardy-Weinberg, on compare les effectifs genotypiques observes aux effectifs attendus sous le modele. On calcule d’abord \(\hat p\), puis les effectifs attendus \(N \hat p^2\), \(N \, 2\hat p \hat q\), \(N \hat q^2\), et l’on mesure l’ecart par la statistique du khi-deux :

\[ \chi^2 = \sum_{\text{genotypes}} \frac{(\text{effectif observe} - \text{effectif attendu})^2}{\text{effectif attendu}} . \]

Reste a savoir a quelle loi comparer cette statistique, c’est-a-dire combien de degres de liberte lui attribuer. Le principe est celui du chapitre sur l’estimation de la variance : on part du nombre de classes, on retranche une unite par contrainte, et une unite par parametre estime sur les donnees.

Il y a trois classes genotypiques. On retranche 1 pour la contrainte que la somme des effectifs egale \(N\). On retranche encore 1 pour la frequence allelique \(\hat p\), estimee a partir de l’echantillon (la frequence \(\hat q = 1 - \hat p\) n’est pas un parametre independant). Il reste donc

\[ \text{ddl} = 3 - 1 - 1 = 1 . \]

C’est une erreur frequente que d’oublier ce second retrait et d’utiliser 2 degres de liberte. Verifions par simulation que la bonne valeur est bien 1. On tire de nombreux echantillons d’une population reellement a l’equilibre, et l’on regarde la distribution de la statistique.

Code
un_test <- function(n, p) {
  nA  <- rbinom(n, size = 2, prob = p)             # echantillon a l'equilibre
  obs <- c(sum(nA == 2), sum(nA == 1), sum(nA == 0))  # AA, Aa, aa
  phat <- (2 * obs[1] + obs[2]) / (2 * n)          # frequence allelique estimee
  qhat <- 1 - phat
  att <- n * c(phat^2, 2 * phat * qhat, qhat^2)    # effectifs attendus
  sum((obs - att)^2 / att)
}

n      <- 200
p_vrai <- 0.6
stat   <- replicate(5000, un_test(n, p_vrai))

c(`moyenne de la statistique` = round(mean(stat), 2))   # 1 pour un khi-deux a 1 ddl
moyenne de la statistique 
                     1.01
Code
tibble(stat = stat) |>
  ggplot(aes(stat)) +
  geom_histogram(aes(y = after_stat(density)), bins = 60,
                 fill = "#4682b4", colour = "white", alpha = 0.65) +
  stat_function(fun = dchisq, args = list(df = 1), colour = "firebrick", linewidth = 1) +
  stat_function(fun = dchisq, args = list(df = 2), colour = "#e07b39",
                linewidth = 1, linetype = 2) +
  coord_cartesian(xlim = c(0, 9), ylim = c(0, 1.2)) +
  labs(x = "statistique du khi-deux", y = "densite")

La consequence pratique se lit sur le taux de fausses alertes. Comme la population simulee est reellement a l’equilibre, un bon test ne devrait la declarer hors equilibre que dans 5 pour cent des cas au seuil de 5 pour cent. C’est bien ce que donne le nombre correct de degres de liberte.

Code
c(`rejet avec ddl = 1 (correct)` = mean(stat > qchisq(0.95, df = 1)),
  `rejet avec ddl = 2 (errone)`  = mean(stat > qchisq(0.95, df = 2)))
rejet avec ddl = 1 (correct)  rejet avec ddl = 2 (errone) 
                      0.0518                       0.0164

Avec 1 degre de liberte, le taux de rejet est proche de 5 pour cent, la valeur visee. Avec 2 degres de liberte, il tombe autour de 1,4 pour cent : le test devient trop prudent, et laisse passer de vraies deviations qu’il aurait du detecter. Ce taux de fausses alertes est l’analogue du taux de couverture du chapitre sur les intervalles de confiance : choisir le mauvais nombre de degres de liberte, comme choisir la mauvaise valeur critique, fausse la garantie annoncee.

AstuceCas a plus d’un parametre estime

Avec trois alleles au lieu de deux, par exemple le systeme des groupes sanguins A, B, O, il y a six genotypes possibles et l’on estime deux frequences alleliques independantes (la troisieme s’en deduit). Le compte devient alors nombre de classes, moins 1 pour le total, moins 2 pour les deux frequences estimees. Le principe ne change pas : un degre de liberte retranche par parametre reellement estime sur les donnees.

7 Une violation typique : la consanguinite

Parmi les ecarts a Hardy-Weinberg, la consanguinite est l’un des plus classiques. Elle survient quand les individus s’accouplent avec des apparentes plus souvent que ne le voudrait le hasard. Ses deux alleles ont alors une chance accrue d’etre des copies d’un meme allele ancestral. On mesure ce phenomene par le coefficient de consanguinite, note \(F\), qui est la probabilite que les deux alleles d’un individu soient identiques par ascendance.

Sous consanguinite, les frequences genotypiques deviennent

\[ f(\text{AA}) = p^2 + Fpq, \qquad f(\text{Aa}) = 2pq(1 - F), \qquad f(\text{aa}) = q^2 + Fpq . \]

La signature est un deficit d’heterozygotes et un exces des deux homozygotes, la frequence allelique restant, elle, inchangee. Simulons-le.

Code
F  <- 0.20
N  <- 200000
ibd <- runif(N) < F                              # les deux alleles identiques par ascendance
a1  <- rbinom(N, 1, p)                            # premier allele : 1 = A, 0 = a
a2  <- ifelse(ibd, a1, rbinom(N, 1, p))          # second : copie du premier, ou tire au hasard
nA  <- a1 + a2

obs    <- prop.table(table(factor(nA, levels = 2:0, labels = c("AA", "Aa", "aa"))))
att_hw <- c(AA = p^2, Aa = 2 * p * q, aa = q^2)   # attendu sous Hardy-Weinberg (meme p)

rbind(observe = round(as.numeric(obs), 3),
      `attendu HW` = round(att_hw, 3)) |> `colnames<-`(c("AA", "Aa", "aa"))
             AA    Aa    aa
observe    0.41 0.383 0.207
attendu HW 0.36 0.480 0.160
Code
tibble(genotype = factor(c("AA", "Aa", "aa"), levels = c("AA", "Aa", "aa")),
       observe = as.numeric(obs), attendu = att_hw) |>
  pivot_longer(c(observe, attendu), names_to = "type", values_to = "frequence") |>
  ggplot(aes(genotype, frequence, fill = type)) +
  geom_col(position = "dodge") +
  scale_fill_manual(values = palette_oa, name = NULL) +
  labs(x = "genotype", y = "frequence")

La frequence de l’allele A vaut toujours 0,6 apres l’operation, mais la proportion d’heterozygotes est passee d’environ 48 a environ 38 pour cent. C’est exactement le genre de deviation que le test du khi-deux detecte, et que le modele de Hardy-Weinberg, en servant de reference, permet de reperer.

8 A retenir

  • Sous accouplement au hasard et en l’absence de selection, mutation, migration et derive, les frequences alleliques restent constantes et les frequences genotypiques valent \(p^2\), \(2pq\) et \(q^2\).
  • Cet equilibre s’atteint en une seule generation, quelles que soient les proportions genotypiques de depart, tant que la frequence allelique est fixee.
  • Hardy-Weinberg est un modele de reference : un ecart aux proportions attendues signale qu’une hypothese est violee, et oriente vers la cause, par exemple un deficit d’heterozygotes en cas de consanguinite.
  • La frequence allelique s’estime en comptant les alleles : \(\hat p = (2 n_{\text{AA}} + n_{\text{Aa}}) / (2N)\).
  • Le test de conformite est un khi-deux a 1 degre de liberte : trois classes, moins un pour le total, moins un pour la frequence allelique estimee. Utiliser 2 degres de liberte fausse le taux de fausses alertes.

La population passe de zero a environ 48 pour cent d'heterozygotes en une generation, tandis que la frequence de l'allele A reste a 0,6. C'est la difference essentielle entre frequence allelique et frequence genotypique : l'accouplement au hasard reorganise les alleles en genotypes selon $p^2$, $2pq$, $q^2$, sans modifier la proportion des alleles eux-memes.

# Les hypotheses du modele ideal

L'equilibre de Hardy-Weinberg ne decrit pas une population reelle quelconque, mais une population **ideale** qui satisfait plusieurs conditions simultanement :

- accouplement au hasard, sans preference liee au genotype ;
- absence de selection, tous les genotypes ayant la meme survie et la meme fecondite ;
- absence de mutation qui transformerait un allele en un autre ;
- absence de migration entre populations ;
- taille de population tres grande, ce qui rend negligeable le hasard des tirages d'une generation a l'autre (la derive genetique).

Ces conditions jouent ici le meme role que le cas ideal dans le chapitre sur la capture-recapture : elles definissent une reference. Quand les proportions observees s'accordent avec Hardy-Weinberg, aucune de ces forces ne se manifeste de facon detectable. Quand elles s'en ecartent, l'ecart oriente vers la cause. Le modele est donc moins une description qu'un **instrument de diagnostic**.

# Estimer la frequence allelique a partir des donnees

En pratique, on ne connait pas $p$ : on l'estime a partir des genotypes observes. Il suffit de compter les alleles. Un individu AA porte deux alleles A, un individu Aa en porte un, un individu aa aucun. Sur un echantillon de $N$ individus, la frequence estimee de A est donc

$$
\hat p = \frac{2 \, n_{\text{AA}} + n_{\text{Aa}}}{2N},
$$

ou $n_{\text{AA}}$ et $n_{\text{Aa}}$ sont les effectifs observes des genotypes correspondants, et $2N$ le nombre total d'alleles dans l'echantillon. Ce point est a retenir pour la suite : la frequence allelique est **estimee sur les donnees elles-memes**, et cela aura une consequence directe sur le test.

# Tester l'equilibre : le khi-deux et ses degres de liberte

Pour decider si une population reelle s'accorde avec Hardy-Weinberg, on compare les effectifs genotypiques observes aux effectifs attendus sous le modele. On calcule d'abord $\hat p$, puis les effectifs attendus $N \hat p^2$, $N \, 2\hat p \hat q$, $N \hat q^2$, et l'on mesure l'ecart par la statistique du khi-deux :

$$
\chi^2 = \sum_{\text{genotypes}} \frac{(\text{effectif observe} - \text{effectif attendu})^2}{\text{effectif attendu}} .
$$

Reste a savoir a quelle loi comparer cette statistique, c'est-a-dire combien de **degres de liberte** lui attribuer. Le principe est celui du chapitre sur l'estimation de la variance : on part du nombre de classes, on retranche une unite par contrainte, et une unite par parametre estime sur les donnees.

Il y a trois classes genotypiques. On retranche 1 pour la contrainte que la somme des effectifs egale $N$. On retranche encore 1 pour la frequence allelique $\hat p$, estimee a partir de l'echantillon (la frequence $\hat q = 1 - \hat p$ n'est pas un parametre independant). Il reste donc

$$
\text{ddl} = 3 - 1 - 1 = 1 .
$$

C'est une erreur frequente que d'oublier ce second retrait et d'utiliser 2 degres de liberte. Verifions par simulation que la bonne valeur est bien 1. On tire de nombreux echantillons d'une population reellement a l'equilibre, et l'on regarde la distribution de la statistique.

```{r}
#| label: test-khi2
un_test <- function(n, p) {
  nA  <- rbinom(n, size = 2, prob = p)             # echantillon a l'equilibre
  obs <- c(sum(nA == 2), sum(nA == 1), sum(nA == 0))  # AA, Aa, aa
  phat <- (2 * obs[1] + obs[2]) / (2 * n)          # frequence allelique estimee
  qhat <- 1 - phat
  att <- n * c(phat^2, 2 * phat * qhat, qhat^2)    # effectifs attendus
  sum((obs - att)^2 / att)
}

n      <- 200
p_vrai <- 0.6
stat   <- replicate(5000, un_test(n, p_vrai))

c(`moyenne de la statistique` = round(mean(stat), 2))   # 1 pour un khi-deux a 1 ddl
```

```{r}
#| label: fig-khi2
#| fig-cap: "Distribution de la statistique du test sur 5000 echantillons issus d'une population a l'equilibre. Elle epouse la loi du khi-deux a 1 degre de liberte (rouge), et non a 2 (orange, en tirets)."
tibble(stat = stat) |>
  ggplot(aes(stat)) +
  geom_histogram(aes(y = after_stat(density)), bins = 60,
                 fill = "#4682b4", colour = "white", alpha = 0.65) +
  stat_function(fun = dchisq, args = list(df = 1), colour = "firebrick", linewidth = 1) +
  stat_function(fun = dchisq, args = list(df = 2), colour = "#e07b39",
                linewidth = 1, linetype = 2) +
  coord_cartesian(xlim = c(0, 9), ylim = c(0, 1.2)) +
  labs(x = "statistique du khi-deux", y = "densite")
```

La consequence pratique se lit sur le taux de fausses alertes. Comme la population simulee est reellement a l'equilibre, un bon test ne devrait la declarer hors equilibre que dans 5 pour cent des cas au seuil de 5 pour cent. C'est bien ce que donne le nombre correct de degres de liberte.

```{r}
#| label: taux-rejet
c(`rejet avec ddl = 1 (correct)` = mean(stat > qchisq(0.95, df = 1)),
  `rejet avec ddl = 2 (errone)`  = mean(stat > qchisq(0.95, df = 2)))
```

Avec 1 degre de liberte, le taux de rejet est proche de 5 pour cent, la valeur visee. Avec 2 degres de liberte, il tombe autour de 1,4 pour cent : le test devient trop prudent, et laisse passer de vraies deviations qu'il aurait du detecter. Ce taux de fausses alertes est l'analogue du taux de couverture du chapitre sur les intervalles de confiance : choisir le mauvais nombre de degres de liberte, comme choisir la mauvaise valeur critique, fausse la garantie annoncee.

::: {.callout-tip collapse="true"}
## Cas a plus d'un parametre estime
Avec trois alleles au lieu de deux, par exemple le systeme des groupes sanguins A, B, O, il y a six genotypes possibles et l'on estime deux frequences alleliques independantes (la troisieme s'en deduit). Le compte devient alors nombre de classes, moins 1 pour le total, moins 2 pour les deux frequences estimees. Le principe ne change pas : un degre de liberte retranche par parametre reellement estime sur les donnees.
:::

# Une violation typique : la consanguinite

Parmi les ecarts a Hardy-Weinberg, la consanguinite est l'un des plus classiques. Elle survient quand les individus s'accouplent avec des apparentes plus souvent que ne le voudrait le hasard. Ses deux alleles ont alors une chance accrue d'etre des copies d'un meme allele ancestral. On mesure ce phenomene par le **coefficient de consanguinite**, note $F$, qui est la probabilite que les deux alleles d'un individu soient identiques par ascendance.

Sous consanguinite, les frequences genotypiques deviennent

$$
f(\text{AA}) = p^2 + Fpq, \qquad f(\text{Aa}) = 2pq(1 - F), \qquad f(\text{aa}) = q^2 + Fpq .
$$

La signature est un **deficit d'heterozygotes** et un exces des deux homozygotes, la frequence allelique restant, elle, inchangee. Simulons-le.

```{r}
#| label: consanguinite
F  <- 0.20
N  <- 200000
ibd <- runif(N) < F                              # les deux alleles identiques par ascendance
a1  <- rbinom(N, 1, p)                            # premier allele : 1 = A, 0 = a
a2  <- ifelse(ibd, a1, rbinom(N, 1, p))          # second : copie du premier, ou tire au hasard
nA  <- a1 + a2

obs    <- prop.table(table(factor(nA, levels = 2:0, labels = c("AA", "Aa", "aa"))))
att_hw <- c(AA = p^2, Aa = 2 * p * q, aa = q^2)   # attendu sous Hardy-Weinberg (meme p)

rbind(observe = round(as.numeric(obs), 3),
      `attendu HW` = round(att_hw, 3)) |> `colnames<-`(c("AA", "Aa", "aa"))
```

```{r}
#| label: fig-consanguinite
#| fig-cap: "Population consanguine (F = 0,20) comparee aux proportions de Hardy-Weinberg de meme frequence allelique. Les heterozygotes sont en deficit, les deux homozygotes en exces."
tibble(genotype = factor(c("AA", "Aa", "aa"), levels = c("AA", "Aa", "aa")),
       observe = as.numeric(obs), attendu = att_hw) |>
  pivot_longer(c(observe, attendu), names_to = "type", values_to = "frequence") |>
  ggplot(aes(genotype, frequence, fill = type)) +
  geom_col(position = "dodge") +
  scale_fill_manual(values = palette_oa, name = NULL) +
  labs(x = "genotype", y = "frequence")
```

La frequence de l'allele A vaut toujours 0,6 apres l'operation, mais la proportion d'heterozygotes est passee d'environ 48 a environ 38 pour cent. C'est exactement le genre de deviation que le test du khi-deux detecte, et que le modele de Hardy-Weinberg, en servant de reference, permet de reperer.

# A retenir

- Sous accouplement au hasard et en l'absence de selection, mutation, migration et derive, les frequences alleliques restent constantes et les frequences genotypiques valent $p^2$, $2pq$ et $q^2$.
- Cet equilibre s'atteint en une seule generation, quelles que soient les proportions genotypiques de depart, tant que la frequence allelique est fixee.
- Hardy-Weinberg est un modele de reference : un ecart aux proportions attendues signale qu'une hypothese est violee, et oriente vers la cause, par exemple un deficit d'heterozygotes en cas de consanguinite.
- La frequence allelique s'estime en comptant les alleles : $\hat p = (2 n_{\text{AA}} + n_{\text{Aa}}) / (2N)$.
- Le test de conformite est un khi-deux a **1** degre de liberte : trois classes, moins un pour le total, moins un pour la frequence allelique estimee. Utiliser 2 degres de liberte fausse le taux de fausses alertes.
